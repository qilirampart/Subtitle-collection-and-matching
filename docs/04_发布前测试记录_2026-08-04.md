## 已知边界

- 封面检测是视觉初筛，只描述封面可见内容，不能代替完整视频合规判断。
- 封面检测固定三路并发；暂停或取消会在当前三张请求返回后生效。
- 匹配服务真实 API 尚未完成，登录、提交、轮询和结果字段只能在 API 交付后进行端到端联调。
- Python 3.9 会产生依赖弃用提示，当前不影响运行；后续打包建议升级到 Python 3.10 或更高版本。
