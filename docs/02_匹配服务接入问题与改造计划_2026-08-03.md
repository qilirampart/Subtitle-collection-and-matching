# YouTube 字幕核验助手：匹配服务接入问题与改造计划

## 当前结论

YouTube 字幕核验助手可以接入小说相似度比对服务新增的短剧字幕匹配能力。现有项目已经具备正确的基础边界：桌面端负责采集公开视频、获取人工或自动字幕、必要时进行 ASR；匹配服务负责保存字幕索引、执行召回并持久化匹配结果。

当前不应复制短剧字幕 SQLite、Qdrant collection 或小说数据到桌面端。桌面端继续作为 API 客户端，通过登录态调用中央匹配服务即可。

## 已对齐的能力

- 已使用匹配服务的登录接口。
- 已对接短剧字幕单条检测接口：`POST /api/v1/drama-subtitles/compare`。
- 已对接短剧字幕批量任务接口：`POST /api/v1/drama-subtitles/tasks`。
- 已可读取任务详情：`GET /api/v1/drama-subtitles/tasks/{task_id}`。
- 字幕轨道语言已可映射为匹配服务分区语言：中文、英文、日文、韩文。
- 原始语言优先、翻译仅在低结果后作为补召回的原则已经明确。

## 接入前必须修复的问题

### 1. 长字幕整段提交会造成漏检

当前助手会将前 1 至 5 分钟字幕拼接为一段长文本后提交。短剧匹配服务的词法召回会限制查询三元词数量，长文本实际会明显偏向开头部分，后续字幕没有得到同等检索机会。

改造方式：按字幕 cue 切成带 overlap 的查询片段，建议每段约 200 至 500 字。每个片段单独检测，再按 YouTube 视频聚合候选。不要把整段视频字幕作为一条唯一查询。

### 2. 缺少 YouTube 侧时间证据

当前 `CaptionDocument` 主要保存合并后的文本，未保留每个待检测片段在 YouTube 视频中的起止时间。匹配服务会返回中台短剧字幕的证据时间，但后续人工核验还需要回到 YouTube 视频定位原始台词。

改造方式：每个查询片段必须保存：

- `video_id`
- 视频 URL
- 视频标题与频道
- YouTube 字幕轨道语言
- 字幕来源：人工字幕、自动字幕或 ASR
- 查询片段序号
- 查询片段起止时间
- 原始 cue 文本与规范化文本

上述字段应随批量任务提交并由匹配服务短剧任务项持久化。

### 3. 批量请求缺少结构化溯源字段

当前 `submit_batch()` 仅提交 URL、文本、平台、标题和描述。`video_id`、频道、上传时间、字幕语言、字幕来源、片段时间范围未结构化传递；仅把它们塞入描述字段会影响后续筛选、导出和复核。

改造方式：扩展批量 CSV 或 Excel 字段，并同步扩展匹配服务短剧任务项字段及输入解析器。

### 4. 任务轮询遗漏 `partial_failed`

`wait_for_task()` 当前只把 `completed`、`failed`、`cancelled`、`paused` 视为结束状态。匹配服务可返回 `partial_failed`，当前实现会继续轮询直至超时。

改造方式：将 `partial_failed` 加入终止状态，同时在 UI 中显示已完成数、失败数和可用结果数。

### 5. 字幕轨道选择过于固定

当前字幕优先级固定为中文、英文、日文、韩文。一个视频存在多条人工或自动轨道时，固定优先级可能选中翻译字幕，而不是需要核验的原始语言轨道。

改造方式：界面展示可用轨道，让操作者选择；至少要把最终选择的轨道代码、字幕类型和语言写入结果。默认可保留优先策略，但不得丢失选择记录。

### 6. `book_id` 与业务所需短剧 ID 的映射待确认

匹配服务当前返回 `book_id`、剧名、集数和字幕证据。若后续业务要求展示稳定的中台剧 ID 或其他业务 ID，需要在匹配服务补充 `book_id` 到业务剧 ID 的映射，并在桌面端同时展示两者。

## 推荐的接入流程

1. YouTube 助手采集频道视频并选择目标视频。
2. 获取人工字幕，缺失时才进入 ASR。
3. 保留原始 cue，按时间切分成查询片段。
4. 每个片段先按原始语言调用短剧字幕匹配。
5. 原语言无候选或低于最终确定的阈值时，再由匹配服务做翻译回退。
6. 按视频聚合各片段候选，保留命中次数、最佳候选和全部时间证据。
7. 导出时同时包含 YouTube 证据时间和中台短剧证据时间，供后续人工核验和维权材料整理。

## 改造顺序

第一阶段：YouTube 助手实现 cue 分段、片段时间范围保留、`partial_failed` 终态处理。

第二阶段：匹配服务扩展短剧任务输入字段和结果导出字段，保存 YouTube 视频与片段溯源数据。

第三阶段：接入按视频聚合的结果视图、任务复核和证据导出。

第四阶段：已由匹配服务接入跨语言翻译回退与用户隔离译文缓存；桌面端仅传递开关并展示 `translation_assisted_match` 复核结果，不在本地私自翻译或简繁转换。详见小说库服务文档 `91_短剧字幕匹配API跨语言翻译回退接入说明_2026-08-09.md`。
