# 全链路验收测试矩阵

## 目标

对独立功能和组合流程分别做真实服务验证。测试生成的媒体、字幕和报告只写入 `output/test_runs` 或既有输出目录，不覆盖用户的采集结果。

## 单链路

| 编号 | 链路 | 验收条件 |
| --- | --- | --- |
| S01 | 频道采集 | 公开频道可返回指定数量的视频 ID、标题、频道和封面地址。 |
| S02 | 视频下载 | 可下载指定前段时长的 MP4，文件存在且非空。 |
| S03 | 音频下载 | 可下载指定前段时长音频，文件存在且可被后续 ASR 使用。 |
| S04 | 直出字幕 | 可获取字幕面板或字幕轨，记录来源、语言、时间范围和文本。 |
| S05 | ASR | 对已下载音频返回非空文字。 |
| S05a | ASR 兜底切段 | 模拟无直出字幕状态并复用已下载音频，生成可匹配片段。 |
| S06 | 封面下载 | 封面文件存在、格式有效、命名为视频 ID。 |
| S07 | 封面检测 | 多模态模型返回结构化风险等级、标签、说明与置信度。 |
| S08 | 字幕切段 | 长字幕生成 320 至 500 字符左右、带时间范围的可匹配片段。 |
| S09 | Excel 导出 | 每个视频仅导出一行完整字幕。 |
| S10 | 匹配服务 | 登录、提交、轮询、三态结果聚合可完成。 |
| S11 | 任务控制 | 暂停、继续、取消的协作式检查点保持可用。 |
| S12 | 状态恢复 | 会话快照可原子写入、重新读取且不持久化密钥。 |
| S13 | 批量字幕与封面 | 至少两条视频可批量准备字幕、下载封面及并发检测，单条失败不应中断其他条目。 |

## 组合链路

| 编号 | 链路 | 验收条件 |
| --- | --- | --- |
| E01 | 下载 -> ASR | 视频或音频下载结果可直接转写。 |
| E02 | 采集 -> 字幕 -> 切段 -> Excel | 采集到的视频能获得字幕并导出完整字幕。 |
| E03 | 采集 -> 封面 -> 检测 | 每个采集视频的封面可关联到同一视频 ID 并产出检测结果。 |
| E04 | 采集 -> 字幕 -> 匹配 | 字幕片段可提交匹配服务，并按视频聚合 `matched`、`review_required`、`not_matched`。 |
| E05 | 全流程 | 采集 -> 下载 -> 字幕/ASR -> 封面检测 -> 匹配 -> Excel 导出均成功，失败项应为单条可定位状态，不中断其余项目。 |

## 执行方式

在已配置 ASR、语言模型及公司内网匹配账号的环境运行：

```powershell
$env:MATCHING_USERNAME = '<匹配账号>'
$env:MATCHING_PASSWORD = '<匹配密码>'
python scripts/run_acceptance_test.py --seconds 60
```

脚本会生成 `output/test_runs/acceptance_时间戳/acceptance_result.json` 和同目录 Markdown 报告。密钥、Cookie、密码均不会写入报告。
