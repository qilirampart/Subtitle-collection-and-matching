# UI 模块化改造进度（2026-08-06）

## 改造判断

现有功能链已经稳定，继续把采集、下载、字幕、ASR、封面和匹配全部堆在一个页面会增加误操作、窄屏溢出和全局锁定风险。采用“工作台 + 独立功能页 + 全流程兼容入口”是合理的渐进式方案。

## 已完成

- 新增左侧导航和工作台页面。
- 现有页面保留为“全流程处理”，不删除原有采集、字幕、ASR、封面和匹配流程。
- 新增独立视频下载页，复用 `YouTubeService.download_video()` 和 `YouTubeAudioService.download_audio()`。
- 下载页支持多行链接、不去重、视频/音频/同时下载、完整或前段范围、音频并发、逐条状态、暂停和取消。
- 新增独立字幕与转写页，支持 YouTube 链接、本地视频、本地音频和已下载素材。
- 字幕页优先直出字幕；无字幕时可选择 ASR 兜底；本地素材直接走 ASR，不要求先解析成 YouTube 视频。
- 新增独立匹配核验页，支持导入当前字幕结果、TXT 和 Excel，复用匹配服务登录、批量提交、进度和服务端任务控制。
- 新增任务中心和设置中心入口。
- 接入 `runtime/session_state.json` 工作区快照：保存视频队列、字幕结果、待 ASR 项、封面结果、独立下载结果和页面任务状态。
- 运行中任务按节流周期保存，程序关闭前保存；下次启动会提示是否恢复上次未完成任务。
- 快照不保存匹配密码、ASR Key、语言模型 API Key 或其他敏感配置。

## 当前边界

- 新页面已经独立可操作，但素材与任务状态仍主要由 `MainWindow` 内存管理。
- 全流程页的旧高级配置区域暂时保留，待配置页完成真实字段迁移后再移除，避免当前版本出现配置入口丢失。
- 任务中心目前已支持当前会话和快照恢复；更细粒度的单条重试记录仍需继续补充。
- 暂未把独立下载完成后的素材自动建档为完整素材实体，当前可通过字幕页“导入已下载素材”继续处理。

## 验证

- `python -m compileall -q app main.py` 通过。
- 工作台、下载、字幕、匹配、任务、设置页面实例化和导航切换通过。
- 自动化测试 `22/22` 通过。
