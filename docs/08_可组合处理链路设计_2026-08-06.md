# 可组合处理链路设计（2026-08-06）

## 结论

不为每一种组合开发一个独立页面，而是拆成两层：

- **功能页**：下载、封面素材、字幕转写、匹配核验，分别可以单独使用。
- **流程页**：选择来源、勾选步骤或选择预设，一次创建一个组合任务。

这样既保留单功能的灵活性，也避免首页出现大量固定按钮。

## 标准步骤

```text
来源
  ├─ 下载媒体（视频 / 音频）
  ├─ 获取封面
  ├─ 检测封面
  ├─ 获取字幕 / ASR 转写
  ├─ 匹配核验
  └─ 导出结果
```

封面步骤内部允许自动串联“获取封面 → 检测封面”；如果已有本地封面，则跳过获取步骤。

## 推荐预设

| 预设 | 步骤 | 用途 |
| --- | --- | --- |
| 完整核验 | 下载 → 封面检测 → 字幕转写 → 匹配 → 导出 | 需要完整素材和核验结果 |
| 下载、封面与匹配 | 下载 → 封面检测 → 字幕转写 → 匹配 | 不立即导出文件 |
| 下载并检测封面 | 下载 → 封面检测 | 投放素材初筛 |
| 下载并匹配字幕 | 下载 → 字幕转写 → 匹配 | 法务字幕核验 |
| 仅下载 | 下载 | 只获取视频或音频 |
| 仅封面检测 | 获取封面 → 检测封面 | 已有采集清单，单独检查封面 |
| 仅匹配 | 匹配 | 已经有 TXT、Excel 或字幕结果 |
| 仅字幕转写 | 字幕转写 | 只需要得到字幕文本 |
| 自定义流程 | 用户自行勾选 | 处理非标准链路 |

## 依赖规则

- 选择“匹配”但没有字幕时，提示“需要先获取字幕，是否自动追加字幕转写”。
- 选择“检测封面”但没有封面时，提示“需要先获取封面，是否自动追加获取封面”。
- 选择“仅匹配”时，不自动下载视频；必须从已有字幕结果或文件导入。
- 选择“仅封面检测”时，不要求字幕或 ASR。
- 下载步骤可选择视频、音频、视频和音频，以及完整内容或前段范围。
- 每个来源独立维护步骤状态，任何一条失败只影响该来源，不阻塞其他来源。

## 流程页布局

1. **来源区**：从采集结果、下载结果、本地文件或链接导入。
2. **流程预设区**：选择预设，或手动勾选步骤。
3. **参数区**：下载范围、音频方案、ASR、封面模型、匹配服务参数。
4. **预览区**：展示实际执行顺序和自动补充的依赖步骤。
5. **执行区**：创建任务，跳转任务中心查看每条来源的步骤状态。
